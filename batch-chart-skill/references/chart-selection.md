# Chart selection and portfolio design

仅在字段类型和抽样结构支持时使用下列候选。

| 数据结构 | 合理候选 | 关键检查 |
|---|---|---|
| 一个数值变量 | 直方图、ECDF、箱线图、密度图、Q–Q图 | 样本量、离散性、偏态、删失 |
| 一个分类变量 | 有序频数/比例图、帕累托图 | 分母、缺失类别、稀有水平 |
| 数值+分类 | 箱线/小提琴/雨云图、抖动散点、带区间的组估计 | 组大小、独立性、方差差异 |
| 两个数值变量 | 散点图、六边形密度图、等高线密度图、带区间的拟合关系 | 重叠、非线性、影响点 |
| 两个分类变量 | 标准化残差热力图、马赛克图、比例图 | 稀疏单元格、分母、排序 |
| 时间+测量值 | 原始轨迹、带区间的趋势、季节图、ACF | 时间间隔、缺口、重复对象 |
| 重复对象 | 个体轨迹、对象内变化图、配对斜率图 | 对象ID、组内相关 |
| 三个以上数值变量 | 相关矩阵、散点矩阵、PCA得分/载荷、聚类热力图 | 缩放、缺失、冗余 |
| 组成数据 | 三元图、对数比图、组成条形图 | 和约束、零值 |
| 自带坐标 | 坐标散点、分箱密度、空间值面 | 坐标系、插值假设 |
| 拟合模型输出 | 残差图、校准图、ROC/PR、系数/重要性、预测区间图 | 目标变量、评估划分、指标适用性 |

Q–Q图、ACF、残差图、ROC/PR、校准图、特征重要性和SHAP图，只有在存在相应统计或预测任务时才生成。

## 候选图排序

从以下维度评价候选：与研究目标的相关性；字段类型和抽样设计适用性；相对于已有图表的新信息；静态论文中的可解释性；对样本量和缺失的稳健性；能否仅凭输入数据复现。

任何存在严重统计适用性问题的候选直接淘汰。在10–30张的范围内按证据覆盖确定组合规模，纳入能补充观察且清晰可读的图。单份、多份输入和数据集均按整套图计数。

给每张候选图分配证据角色，包括数据可信度、总体景观、主要定量证据、对照或替代解释、分解或分层、正交验证、稳健性或边界。在证据互补且易读的候选中，优先采用图型更丰富、视觉表现更鲜明的组合。

如果数据存在匹配对象、重复测量、种子、折或成对实验，先判断研究问题是否关注对象内变化。仅比较边际分布可能被对象间差异掩盖，应在适当时使用配对连线、差值分布或对象内效应图。

## 数据足够丰富时的默认菜单

这不是强制清单，应按数据替换：缺失模式、分组样本数、关键变量分布、ECDF或Q–Q、分组分布、带不确定性的组估计、关键双变量关系、密度型双变量图、相关热力图、精选散点矩阵、分类关联热力图、时间趋势或重复对象轨迹、季节性或自相关诊断、PCA得分、PCA载荷或聚类热力图。

只有在两者揭示不同现象时，才同时保留普通散点图和密度型双变量图。

以下情况通常属于冗余：同一变量同时保留直方图、密度图、箱线图和小提琴图；饼图与百分比条形图展示同一组成；同一数据切片的两种排序；同一比较只替换相近指标或坐标方向。只有当第二张图揭示分布尾部、重叠、异方差、对象内变化或其他独特结构时才保留。

## 正文与补充材料

正文优先放回答核心问题且重复最少的图。数据质量诊断、稳健性分析、扩展变量面板和次要亚组分析通常放入附录或补充材料；如果它们本身就是研究问题的一部分，则可进入正文。
