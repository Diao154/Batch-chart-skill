# Publication figure design

本参考用于把候选图表组织为可发表、可审查的学术图表组合。不要照搬某一期刊的视觉外观；如果用户指定期刊，优先遵守其最新指南，否则使用通用学术规范。

## 一、先写图表组合契约

绘图前用简短工作记录回答：

```text
研究问题或探索性目标：
数据能支持的主张边界：
目标阅读场景与最终尺寸：
图表序列：
  图号 | 科学问题 | 证据角色 | 独特信息增益 | 正文/补充材料
主要证据：
验证、稳健性或边界证据：
需要说明的统计量：
最可能受到审稿人质疑的点：
```

没有明确研究假设时，把“主张”改为暂定的探索性观察，例如“描述样本分布与变量关系”，不要从相关性写出因果结论。

## 二、用证据角色组织10–30张图

每张图只需承担一个清晰的主要角色，但一组图应形成递进关系：

| 证据角色 | 要回答的问题 |
|---|---|
| 数据可信度 | 缺失、重复、量纲、覆盖范围和异常结构是否影响后续解释？ |
| 总体景观 | 样本、类别、时间、空间或变量分布的主要形态是什么？ |
| 主要定量证据 | 核心差异、关联、趋势或组成关系是否存在？ |
| 对照或替代解释 | 主要观察是否只是基线、混杂、尺度或分母造成的？ |
| 分解或分层 | 哪些变量、组别、时期或层级贡献了总体模式？ |
| 正交验证 | 换一种测量、统计表达或数据子结构后是否得到相容结论？ |
| 稳健性或敏感性 | 合理的参数、阈值、变换或估计方法变化会不会改变结论？ |
| 边界或失败案例 | 模式在哪里减弱、反转、失效或无法推广？ |

按证据覆盖决定图集规模，优先采用图型多样、层次清楚且信息互补的组合。只换配色、坐标方向、图形种类或近义指标，通常不构成新的证据角色。

对每张候选图执行必要性测试：

1. 删除它会失去哪一条独特信息？
2. 这条信息是否建立、推进、限定或质疑主要观察？
3. 它是否只是已有图的另一种编码？
4. 它更适合正文、补充材料、合并为多面板，还是删除？

## 三、多面板图的证据结构

多面板图默认围绕一个主要问题组织，面板承担不同的推断角色，而不是把几个独立小故事拼成仪表盘。常用顺序为：

`定义对象或设计 → 主要比较 → 分布/残差/机制 → 对照、稳健性或边界`

- 最有决定性的面板占据主要位置或较大面积；辅助面板视觉上安静但仍可判断。
- 面板字母表示阅读顺序，不预设某个字母一定是什么图。
- 比较面板保持条件颜色、名称、样本定义、误差定义和尺度一致；差异必须披露。
- 若移除某面板不影响整张图的结论，把它合并、下放补充材料或删除。
- 不强迫证据重要性不同的面板等大；但被设计为同级比较的面板，其绘图区、共享边界和间距应在最终渲染中对齐。

## 四、视觉层级与编码

- 使用白色背景作为普通数据图默认；黑色背景仅用于确有需要的成像图版。
- 每套图使用与数据语义匹配的鲜明配色。可区分的主色标识主要系列，中性或低饱和色承载背景与基线，强调色标识关键证据。
- 同一条件或组别跨图保持颜色、符号和标签一致。不要把顺序色阶当作无序类别色板。
- 直接标签能减少视线往返时优先直接标签；重复图例改为共享图例。
- 不默认显示网格线、数据标签或上下右边框；仅在它们帮助读数时保留。
- 刻度使用数据语义合理的步长。计数优先整数刻度；调整画布后重新检查自动刻度。
- 标签位置应根据数据和不确定性上界计算，而不是用固定坐标硬编码。
- 不用不透明白框掩盖穿过标签的数据线；应移动标签、改变布局或减少注释。

## 五、统计与图注最低信息

图注应脱离正文仍可理解。对每张定量图，按适用性说明：

- 点、柱、箱体、线、色带或阴影各代表什么；
- `n` 的精确定义以及独立观测单位；
- 中心统计量和离散/区间定义；
- 配对、非配对、重复测量或嵌套结构；
- 检验或模型、多个比较校正和精确 `p` 值（如果确实进行了推断）；
- 对数、标准化、缩放、平滑、插值、聚类或降维方法；
- 任何排除规则及处理前后样本量。

不要为探索性图虚构检验、误差条或显著性星号。视觉事实用描述性语言；推断性结论只有在设计与方法支持时才出现。

## 六、最终尺寸设计

字号是否合格取决于论文中的最终物理尺寸，不取决于绘图窗口大小。

- 如果期刊或模板给出栏宽，按该宽度绘制和验收；否则先确定单栏、双栏或报告页面的目标用途。
- 除非目标期刊另有规定，最终渲染的任何字形不得低于5 pt；普通轴、刻度和图例通常以最终尺寸约7–9 pt为起点，再根据密度调整。
- 数学上下标可能比父字号更小，必须检查导出的实际字形，而不是只看源码中的 `fontsize`。
- 长标签与分配空间不匹配时，优先重排、换行、缩短或扩大画布，不以无限缩小字体解决。
- 主证据应在最终尺寸和灰度/常见色觉条件下仍比辅助信息更醒目。

## 七、正文与补充材料

正文保留决定性证据、必要对照和会改变结论的边界。补充材料放数据质量详情、替代估计、扩展变量、次要亚组或不改变主结论的稳健性分析。负面结果如果会改变解释，必须保留在正文或明确可见的位置。
